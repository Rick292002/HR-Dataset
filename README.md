# HR-Dataset

PT-br
Este é um mini projeto de análise de dados onde baixei um dataset na plataforma Kaggle sobre uma base de dados de uma empresa com diversos funcionários. 

A análise foi feita em um algoritmo em Python para realizar limpeza e tratamento dos dados além de responder perguntas de BI (Business Inteligent) e um Dashboard no Power BI.

Link do Kaggle: https://www.kaggle.com/datasets/rohitgrewal/hr-data-mnc

US
This is a mini data analysis project in which I downloaded a dataset from the Kaggle platform containing a database from a company with numerous employees.

The analysis was performed using a Python algorithm to clean and process the data, as well as to answer BI (Business Intelligence) questions and create a dashboard in Power BI.

Link of Kaggle: https://www.kaggle.com/datasets/rohitgrewal/hr-data-mnc
